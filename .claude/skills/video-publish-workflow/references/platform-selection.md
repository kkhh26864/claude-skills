Which platforms to publish to based on video content type.

## Decision Table by Content Type

### 东南亚旅行 / 旅居生活
泰国、兰卡威、马来西亚、曼谷日常、旅居开销、当地体验

→ **TikTok ✅ + 抖音 ✅ + YouTube 生活频道 ✅**
- TikTok: 海外华人高度共鸣，东南亚相关 hashtag 流量大
- 抖音: "旅居东南亚"赛道热门，完播率高
- YouTube: 长视频做 vlog，短视频发 Shorts

---

### 骑行 / 摩托车
骑行日记、线路分享、摩托车保养/购买、驾照

→ **TikTok ✅ + 抖音 ✅ + YouTube 生活频道 ✅**
- 骑行内容在三端都有稳定垂直受众
- 干货类（驾照/选车）在 YouTube 搜索流量好

---

### 实用干货
签证攻略、汇率/花费、当地生活成本、洗衣/租房/交通

→ **TikTok ✅ + 抖音 ✅ + YouTube 生活频道 ✅**
- 干货是搜索型内容，YouTube 长尾流量最强
- 抖音 + TikTok 短视频快速触达目标人群

---

### 长沙 / 国内生活
长沙旅游、国内骑行、家乡内容

→ **抖音 ✅ + YouTube 生活频道 ✅**（TikTok 可选，国内题材对海外受众吸引力较低）
- 抖音本土受众对长沙/国内内容更有共鸣
- TikTok 可发但不优先，加上旅行角度（"长沙人眼中的…"）会更适合

---

### 技术内容
抓包工具、开发技巧、网络工具、效率软件、硬件折腾

→ **YouTube 技术频道 ✅ 独发**（不发 TikTok/抖音）
- 技术受众在短视频平台转化极差
- 确认发到"自由码农"技术频道，不要发到生活频道

---

### 纯娱乐 / 搞笑片段
无实用价值的趣事、偶发事件

→ **TikTok ✅ + 抖音 ✅**（YouTube 不值得单独发，除非是更长 vlog 的一部分）

---

## YouTube 频道选择

发 YouTube 时必须确认频道：

| 内容 | 频道 |
|------|------|
| 旅行、骑行、旅居生活、长沙日常 | **自由码农的生活** |
| 抓包、工具测评、开发教程、网络/硬件 | **自由码农**（技术频道）|

---

## 视频时长 → 发布策略

| 时长 | 策略 |
|------|------|
| ≤60s 竖屏 | TikTok + 抖音 同步发；YouTube 作为 Shorts 可选 |
| 1–3 min 竖屏 | TikTok + 抖音 发（抖音支持长视频）；YouTube Shorts 截取 60s 精华片段 |
| >3 min 横屏 vlog | YouTube 生活频道主发；剪出 60s 竖屏版发 TikTok + 抖音 |
| >3 min 横屏 技术 | YouTube 技术频道主发；不必同步短视频 |

---

## 快速决策口诀

```
东南亚 + 骑行 + 干货  →  三端全发
长沙 / 国内           →  抖音 + YouTube生活（TikTok可选）
技术内容              →  只发 YouTube技术频道
```
